# Contributing

Thanks for helping with opentopost.

1. Open an issue first for anything bigger than a small fix, so we can agree on the approach.
2. Fork the repository and create a branch.
3. Run it locally with the steps in [docs/self-hosting.md](docs/self-hosting.md). [docs/architecture.md](docs/architecture.md) explains how the parts fit.
4. Before you open a pull request, run `npm run lint` and `npm run build`. The same checks run in CI.
5. Keep each pull request to one change, and say what it fixes and how you tested it.

By contributing you agree that your work is licensed under the [AGPL-3.0](LICENSE), the same as the project.

To report a vulnerability, read [SECURITY.md](SECURITY.md). Do not open a public issue for it.
